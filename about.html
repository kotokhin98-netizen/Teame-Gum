Кто мы

Мы — команда из трёх участников, которая развивает навыки веб-разработки и DevOps на практике. Создаём сайты на HTML, CSS и JavaScript, работаем с Git и настраиваем автоматическую публикацию проектов через GitHub Actions и GitHub Pages.

Для нас важны понятный код, доступный интерфейс, совместная работа и постоянное улучшение результата.
